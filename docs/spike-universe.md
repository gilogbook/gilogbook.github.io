## 5. 우선주 (1)

| # | 종목명 | 종목코드 | corp_code | 시가총액 |
|---|---|---|---|---|
| 25 | LG생활건강우 | 051905 | **없음** | 2,233억 |

`051905`는 우선주입니다. `CORPCODE.xml`에 등록돼 있지 않습니다. 우선주는 별도 법인이 아니라 같은 회사의 다른 주식 종류라, DART에는 보통주 `051900`(LG생활건강, corp_code `00356370`) 하나만 존재합니다.

무작위 선정 과정에서 우연히 들어왔지만 **그대로 둡니다.** 스크리너가 걸러내지 못하면 이렇게 됩니다.

| | 보통주 051900 | 우선주 051905 |
|---|---|---|
| 종가 | 300,000원 | 106,500원 |
| 시가총액 | 44,927억 | **2,233억** |

EBIT은 회사 전체 값인데 시가총액은 우선주 몫만 잡히므로, **이익수익률이 약 20배 과대 계상되어 순위 최상위로 올라옵니다.** 실제로 싼 게 아니라 계산이 틀린 것입니다.

**판별 규칙:** 한국 종목코드는 끝자리가 `0`이 아니면 우선주입니다. `051905`의 `5`가 그 표시입니다. 유니버스 필터에 이 조건을 넣어야 합니다.

## 결산월 항목 처리

국내 상장사는 사실상 전부 12월 결산이라 비12월 결산 표본을 따로 넣지 않았습니다. **결산월 분기 처리는 우선순위가 낮다**는 것도 유효한 결론이며, 전체 유니버스 단계(D22~D28)에서 실제 분포를 확인한 뒤 판단합니다.

30종목을 돌린 뒤 아래 표를 채웁니다. 이 표가 글 4번(「2,500개를 돌려보니」)의 원재료입니다.

| 종목 | EBIT(a)<br>영업이익 | EBIT(b)<br>매출총이익−판관비 | EBIT(c)<br>세전이익+이자비용 | EV | 순운전자본 | 순고정자산 | 이익수익률 | 자본수익률 | 실패사유 |
|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | |

**실패한 행은 지우지 마세요.** 실패사유 열이 이 표에서 가장 값어치 있는 부분입니다.

실패사유 분류 예시

- `계정없음` — 해당 계정과목이 재무제표에 존재하지 않음
- `계정명불일치` — 같은 항목을 다른 이름으로 표기
- `지주왜곡` — 값은 나오지만 의미가 없음
- `음수EBIT` — 적자
- `우선주` — 유니버스 진입 전 제외 (정상)
- `금융제외` — 규칙대로 걸러짐 (정상)

| # | 항목 | 근거가 될 관찰 |
|---|---|---|
| 1 | EBIT 정의 | (a)(b)(c) 세 값의 차이가 순위를 얼마나 바꾸는가 |
| 2 | 지주회사 제외 여부 | 11~15·22번의 지표가 의미 있게 나오는가 |
| 3 | 금융·유틸리티 제외 범위 | 16~18·26·29번이 제대로 걸러지는가. 특히 26번(벤처캐피탈)이 경계 |

`전략규칙.md`의 이식 결정 7건 중 1~4번이 여기서 정해집니다. 위 5번(우선주)은 스파이크 준비 과정에서 새로 발견되어 추가된 항목입니다.

나머지 3건(시가총액 하한, 종목 수, 생존편향)은 전체 유니버스 단계(D22~D28)와 백테스트 단계에서 정합니다.

## 참고 — DART 조회 방식

```
https://opendart.fss.or.kr/api/fnlttSinglAcntAll.json
  ?crtfc_key={인증키}
  &corp_code=00126380
  &bsns_year=2025
  &reprt_code=11011      # 사업보고서
  &fs_div=CFS            # 연결재무제표 (별도는 OFS)
```

- `corp_code`는 위 표의 8자리 값
- `reprt_code=11011`이 사업보고서(연차)
- 지주회사는 `CFS`와 `OFS`를 모두 받아 비교해볼 것
- 인증키는 코드에 직접 적지 않습니다. 환경변수 또는 GitHub Secrets를 씁니다

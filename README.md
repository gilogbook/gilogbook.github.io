# gilogbook.github.io

마법공식 모의 운용 기록 사이트 https://gilogbook.github.io 의 저장소입니다. 실제 자금이 투입되지 않은 모의 운용이며, 투자 권유가 아닙니다.

## 기록 파일 (저장소 루트)

- `meta.json` — 개시 전(2026-09-13)에 확정한 운용 규칙. 소급 수정하지 않습니다. 그 뒤 달라진 서술은 사이트 방법론 §8 에 적습니다
- `holdings/` — 리밸런싱 날짜별 보유 종목. 덮어쓰지 않습니다
- `nav.csv` — 거래일별 순자산과 지수. 추가만 합니다
- `nontrading.json` — 비거래일 판정 · `events.csv` — 사건 기록(추가만)
- `scripts/` · `.github/workflows/` — 일별 수집 · 이벤트 감지 · 배포
- `site/` — 사이트(Astro)

## 기록이 아닌 파일

- `strategies/` · `markets/` — 2026-08-18 에 만든 구조 뼈대입니다. 순위 산출 코드는 아직 이 저장소에 공개하지 않았습니다
- `docs/spike-universe.md` — 2026-08 데이터 검증용으로 고른 30종목 표본입니다. 추천이 아니며, 결과표는 채우지 않았습니다(결과는 글 「2,765개를 돌려보니」)
